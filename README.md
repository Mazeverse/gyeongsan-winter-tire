# 경산 윈터타이어 랜딩페이지

넥센타이어 경산점 전화 접수 → 제품 입고 안내 → 방문 장착 안내 페이지입니다.

## 배포
GitHub 저장소 `gyeongsan-winter-tire`에 파일을 업로드한 뒤 Vercel에서 Import Project → Other → Deploy를 선택하세요. 빌드 명령은 필요 없습니다.

## 배포 후 확인
- 실제 전화번호/주소/운영 조건을 확인하세요.
- Vercel 배포 주소가 정해지면 `index.html`에 canonical URL을 추가하고, `sitemap.xml`을 만들어 Google/Naver에 제출하세요.
